# South India Weather Impact Dashboard 🌦️

A localized, automated weather dashboard that processes high-resolution meteorological data (WeatherNext 3, ECMWF) into actionable, layman-friendly indices for South India. 

Instead of displaying raw atmospheric metrics, this pipeline translates complex arrays (CAPE indices, 1-hour precipitation, wind gusts) into practical daily metrics like the **Two-Wheeler Safety Gauge** and the **Laundry Countdown Timer**.

## Features
* **Actionable Impact Scores:** Converts raw precipitation and wind data into Go/No-Go activity gauges using custom boolean logic.
* **Hyper-Localized Bounds:** Geographic extent is strictly constrained to the South Indian peninsula to monitor convective activity and the North East Monsoon.
* **Automated Data Pipeline:** Uses GitHub Actions to poll model runs every 3 hours, recalculate indices, and update the live dashboard without manual intervention.
* **Custom Visualizations:** Utilizes discrete, interleaved colorbar sequences for clear, accessible public warnings.

## How It Works
1. **Data Ingestion:** The Python backend pulls experimental 1-hour datasets. 
2. **Logic Processing:** Applies weighted blending formulas to calculate activity safety scores (e.g., combining visibility, wind, and rain for commuter safety).
3. **Frontend Rendering:** Pushes the calculated JSON data to the static frontend hosted on GitHub Pages.
